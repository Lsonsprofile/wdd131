Project 1: TechHub Blog (WDD 131 Final Project)

Project Overview

Emmanuel Ndogo – WDD 131 Final Project Summary

This dynamic tech blog consists of three fully responsive pages built from scratch using contemporary HTML5, CSS3, and vanilla JavaScript – no third-party frameworks or templates were used.

Key Features by Page:

devhub.html (Home Page)

  • Hero section that randomly showcases a featured article on every visit (JavaScript-powered)
  • On large screens: Sidebar displays latest articles
  • On mobile devices: Sidebar collapses below hero for optimal readability
  • Additional sections: Spotlight and Gossip
  • Social media links permanently visible in responsive sidebar

articles.html

  • Dynamically loads all articles via JavaScript DOM manipulation from an array of objects
  • Real-time search across titles, authors, and summaries
  • Filter by favorites functionality
  • Save articles using localStorage
  • Favorite status instantly reflected with static heart buttons and toast notifications
  • Responsive grid layout: Three columns on desktop, one column on mobile

about.html

  • Personal biography section
  • Fully accessible contact form with proper labels and required fields
  • Client-side validation
  • Confirmation message and form reset upon successful submission
Technical Implementation:
  • All images include loading="lazy" for performance optimization
  • External CSS cleanly separated
  • Passes HTML and CSS validation with zero errors
  • JavaScript demonstrates: multiple functions, DOM manipulation, event listeners, conditional logic, arrays and array methods, objects, template literals, and localStorage usage
Content Sources:
  • Article Content: Originally written by AI for project demonstration purposes
  • Images: Sourced from Google Images and free stock photo websites
  • Educational Use: All external content used for educational purposes only

Project 2: Front-End Designer Audit Tool

Project Overview

This tool was built from scratch using modern HTML5, CSS3, and vanilla JavaScript to help designers and developers audit web pages for essential front-end best practices. The tool features URL analysis, automated checklist validation, source code extraction, and integration with industry-standard validation services.

Core Features:
  • Real-time URL auditing with automated HTML analysis
  • Interactive checklist with 7 essential categories
  • Source code extraction and download functionality
  • Integration with official W3C validation services
  • Responsive design that works on all devices
  • Browser-based (no data sent to external servers)

Core Validation Services & Credits

1. W3C HTML Validator

URL: https://validator.w3.org/nu/

How it works: Official W3C HTML validation service that checks HTML markup against current web standards and returns detailed error reports.

2. W3C CSS Validator

URL: https://jigsaw.w3.org/css-validator/

How it works: Official W3C CSS validation service that analyzes CSS stylesheets for syntax errors and compatibility issues.

3. WAVE Accessibility Evaluation Tool

URL: https://wave.webaim.org/

How it works: Comprehensive accessibility testing tool that checks for WCAG compliance including contrast ratios and keyboard navigation.

4. Google PageSpeed Insights

URL: https://pagespeed.web.dev/

How it works: Performance analysis tool that audits webpage loading speed and Core Web Vitals.

5. FreeFormatter HTML Validator

URL: https://www.freeformatter.com/html-validator.html

How it works: Alternative HTML validation service for uploading files or pasting source code directly.

API & Service Providers

AllOrigins CORS Proxy

Service: https://api.allorigins.win/

How it works: Provides a workaround for CORS restrictions when fetching webpage content for analysis.

Technology Stack

Google Fonts

Fonts: Inter & JetBrains Mono – loaded from Google's CDN for modern typography.

Local Storage API

Technology: Web Storage API – used to save audit progress within the browser session.

How the Audit Tool Works

URL Audit Process:

  1. Fetch: Uses fetch API with CORS proxy to retrieve webpage HTML
  2. Parse: HTML parsed using DOMParser to create virtual DOM
  3. Analyze: Automated checks run against parsed DOM structure
  4. External Validation: URLs constructed with parameters and opened in new tabs

Source Code Extraction:

  1. Capture: Raw HTML source code saved from fetched response
  2. Format: Code formatted with line numbers for readability
  3. Export: Users can copy or download HTML for offline validation

Privacy & Security

  • No Data Collection: Both tools run entirely in your browser
  • No API Keys Required: All validation services are free and open
  • Transparent Processing: Source code available for inspection
  • User Control: All data stays in your browser and can be cleared anytime

Educational Value Demonstrated

  • Progressive Enhancement: Works without JavaScript where possible
  • Responsive Design: Adapts to different screen sizes
  • Accessibility First: Built with semantic HTML and keyboard navigation
  • Modern JavaScript: Uses ES6+ features with fallbacks for compatibility
  • Performance Awareness: Minimal dependencies and optimized loading
  • Best Practices: Clean separation of concerns, validation, and error handling
