Project Overview

Emmanuel Ndogo – Front-End Designer Audit Tool

This tool was built from scratch using modern HTML5, CSS3, and vanilla JavaScript to help designers and developers audit web pages for essential front-end best practices. The tool features URL analysis, automated checklist validation, source code extraction, and integration with industry-standard validation services.

Core Features:

  • Real-time URL auditing with automated HTML analysis
  • Interactive checklist with 7 essential categories
  • Source code extraction and download functionality
  • Integration with official W3C validation services
  • Responsive design that works on all devices
  • Browser-based (no data sent to external servers)

Core Validation Services & Credits

1. W3C HTML Validator

URL: https://validator.w3.org/nu/

How it works: This is the official W3C HTML validation service. When you click the "HTML Validator" button, it sends the webpage URL to W3C's validation engine which checks the HTML markup against current web standards. It returns detailed error reports, warnings, and suggestions for fixing invalid HTML.

2. W3C CSS Validator

URL: https://jigsaw.w3.org/css-validator/

How it works: The official W3C CSS validation service analyzes all CSS stylesheets linked to the webpage. It checks for syntax errors, invalid properties, browser compatibility issues, and accessibility-related CSS problems. Results show line-by-line errors and warnings.

3. WAVE Accessibility Evaluation Tool

URL: https://wave.webaim.org/

How it works: Developed by WebAIM, WAVE is a comprehensive accessibility testing tool. It analyzes the webpage and visualizes accessibility issues directly on the page. It checks for WCAG (Web Content Accessibility Guidelines) compliance including contrast ratios, keyboard navigation, ARIA attributes, and semantic structure.

4. Google PageSpeed Insights

URL: https://pagespeed.web.dev/

How it works: Google's performance analysis tool that audits webpage performance on both mobile and desktop. It simulates real-world loading conditions and provides scores for Core Web Vitals (Largest Contentful Paint, First Input Delay, Cumulative Layout Shift), along with optimization suggestions for images, JavaScript, CSS, and hosting.

5. FreeFormatter HTML Validator

URL: https://www.freeformatter.com/html-validator.html

How it works: An alternative HTML validation service that allows you to upload HTML files or paste source code directly. It's particularly useful for local file validation when you can't publicly host a webpage. It provides detailed error messages with line numbers and explanations.

API & Service Providers

AllOrigins CORS Proxy

Service: https://api.allorigins.win/

How it works: This tool provides a workaround for CORS (Cross-Origin Resource Sharing) restrictions. When auditing URLs, browsers block direct fetching from different domains for security. The AllOrigins proxy acts as an intermediary that fetches the webpage content and returns it with appropriate CORS headers, allowing the audit tool to analyze any public webpage.

Technology Stack

Google Fonts

Fonts: Inter & JetBrains Mono

How it works: These fonts are loaded from Google's CDN (Content Delivery Network). They provide clean, modern typography that enhances readability. The fonts are served with proper font-display settings to prevent layout shifts during loading.

Local Storage API

Technology: Web Storage API

How it works: The browser's localStorage is used to temporarily save audit progress and URL history. This allows the tool to remember your work within a single browser session. No data is sent to external servers - everything remains in your browser.

How the Tool Works

URL Audit Process:

  1. Fetch: The tool uses fetch API with CORS proxy to retrieve webpage HTML
  2. Parse: The HTML is parsed using DOMParser to create a virtual DOM
  3. Analyze: Automated checks run against the parsed DOM structure
  4. External Validation: URLs are constructed with parameters and opened in new tabs

Source Code Extraction:

  1. Capture: Raw HTML source code is saved from the fetched response
  2. Format: Code is formatted with line numbers for readability
  3. Export: Users can copy or download HTML for offline validation

Privacy & Security

  • No Data Collection: This tool runs entirely in your browser
  • No API Keys Required: All validation services are free and open
  • Transparent Processing: Source code is available for inspection
  • User Control: All data stays in your browser and can be cleared anytime
