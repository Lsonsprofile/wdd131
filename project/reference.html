Emmanuel Ndogo – WDD 131 Final Project (summary)

This dynamic tech blog consists of three fully responsive pages built from scratch using contemporary HTML5, CSS3, and vanilla JavaScript – no third-party frameworks or templates were used.

devhub.html (Home) features a nice hero section that randomly showcases a featured article on every visit, powered by JavaScript. On large screens, a sidebar displays the latest articles; on mobile devices, it collapses below the hero for optimal readability. Two additional sections spolight and gossip. Social media links are permanently visible in the responsive sidebar.

articles.html dynamically loads all articles via JavaScript DOM manipulation from an array of objects. Users can search titles, authors, and summaries in real time, filter by favorites, and save articles using localStorage. Favorite status is instantly reflected with static heart buttons and a toast notification. The grid layout automatically adjusts from three columns on desktop to one column on mobile.

about.html contains a personal biography and a fully accessible contact form with proper labels, required fields, and client-side validation. Upon successful submission, JavaScript displays a confirmation message and resets the form.

All images include loading="lazy" for performance, external CSS is cleanly separated, and the site passes HTML and CSS validation with zero errors. JavaScript demonstrates multiple functions, DOM manipulation, event listeners, conditional logic, arrays and array methods, objects, template literals, and localStorage usage as required.
